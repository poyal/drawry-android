# Android 검증 기준

최종 디자인과 기준 v1.0은 확정했으며 현재 앱은 구현 대기 안내 화면이다. 실제 기록 화면과 아래 기능 검증은 새 UI 연결 후 수행한다.

## 유지한 자동 테스트

- Kotlin 코어: 암호화 왕복·변조·잘림·잘못된 암호·복구 키·데이터 제약·독립 테스트 벡터
- 낙서: v1/v2 데이터 읽기, 좌표 변환, 지우개 판정, 획·점 수 제한
- Android 저장소: SQLCipher 암호화, 초안·휴지통, 병합/교체 복원, 잠금 설정 보존, 실패 시 데이터 보존

## 새 화면 구현 후

사진 가져오기 → 글 작성 → 낙서 → 저장 → 재열기 → 공유 → 백업/복원을 검증한다. 일기당 미디어 10개·300MiB, 영상 3개·각 30초·합계 60초 제약과 원본 보존을 확인한다.

기기 잠금, 백그라운드 화면 보호, 권한 거부, 디스크 부족, 취소·중단 복구, 삭제·복원·영구 삭제를 확인한다. API 26 및 현재 Android, 16KB 페이지 기기, 작은 화면·가로 화면·태블릿·키보드·TalkBack·200% 글씨를 검증한다.

확정한 [디자인 기준](design/DESIGN_SYSTEM.md)에 따라 UI 테스트를 만든다. 개인 기록이 없는 전용 에뮬레이터에서만 전체 기기 테스트를 실행한다.
