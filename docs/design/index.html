03 달라지지 않는 중심

모든 디자인에서 사진 위에 직접 그리는 경험을 중심에 둡니다.

01 / CONTENT

사진이 이야기의 시작

사진을 선택해 그 위에 직접 그리고, 짧은 글로 하루를 남깁니다. 날짜·기분·태그는 기록을 도와주는 선택 항목입니다.

02 / EXPRESSION

내 손으로 더하는 한 획

사진 위에 그리고, 지우고, 되돌립니다. 원본은 보존하고 편집 내용은 별도로 관리합니다.

03 / PRIVACY

나만을 위한 기록

계정 없이 기기에 암호화해 보관합니다. 공유는 직접 선택하고, 기기 변경을 위한 백업은 따로 만듭니다.

탐색
기록 · 캘린더 · 설정의 3개 목적지. 작성은 독립된 주 행동.
입력
Android Photo Picker → 사진 위 그리기 → 그림 적용 → 짧은 글 → 일기 저장.
접근성
최소 48dp 터치 영역, 본문 16sp 기준. TalkBack·200% 글씨 검증.
적응형
600dp 미만 하단 탐색, 600dp 이상 탐색 레일, 840dp 이상 목록·상세 분할을 설계 목표로 합니다.
상태
빈 기록 · 초안 복구 · 권한 거부 · 저장 실패 · 백업 실패를 각각 설계합니다.
