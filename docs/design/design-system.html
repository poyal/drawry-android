02 / COLOUR

종이색 바탕, 작은 테라코타.

바탕·엽서·조작부를 구분합니다. 사진과 그린 선의 색은 그대로 유지합니다.

역할로 색을 고릅니다.

주 행동은 actionBackground + actionText, 본문은 text, 보조 글은 textSecondary를 씁니다. 장식 구분선과 입력 경계는 별도 토큰입니다. 시스템·라이트·다크를 지원하며 앱 화면 테마는 리넨 하나입니다. 아이콘 표지는 같은 테마의 surfaceSoft #EEE2D9를 기준으로 하며, 사진의 자연색과 검정 붓선을 유지합니다.

리넨 스케치북.

2026.10.21 확정. 이 원본 한 장을 Drawry의 앱 아이콘 기준으로 사용합니다.

형태를 유지합니다.

왼쪽의 흰 링 두 개, 둥근 스케치북 표지, 오른쪽 종이 가장자리, 흰 테두리의 풍경 사진, 사진을 가로지르는 고리 모양 붓선이 한 구성입니다.

하나의 원본에서 사용합니다.

아이콘의 색감 기준

표지는 앱의 surfaceSoft #EEE2D9를 제작 기준으로 사용했습니다. 사진·붓선 색상은 승인 이미지의 대표 참고값입니다. 실제 아이콘에는 질감·빛·그림자가 있으므로 확정 PNG의 표현을 우선합니다. 앱 화면의 조작부와 글자색은 02 색상의 토큰을 사용합니다.

밝은 주변 바탕

어두운 주변 바탕

72 / 48 / 32 CSS px의 표시 예시입니다. 주변 바탕만 다르며 아이콘 파일은 같습니다. 실제 Android 런처에서의 크기·마스크 검수는 구현 단계에서 진행합니다.

앱 아이콘과 화면 아이콘.

스케치북은 앱을 식별하는 브랜드 이미지입니다. 펜·지우개·탐색처럼 누르는 UI 아이콘은 기존 24dp 선형 기준을 사용합니다. 상단 이름은 같은 글자색의 drawry :)를 유지합니다.

Android 구현 인계.

이번 확정 원본은 불투명 정사각 PNG입니다. 적응형 런처용 전경·배경과 시스템 테마용 단색 자산은 구현 단계에서 준비하고 확인합니다. 임시 D 런처 리소스는 아직 교체하지 않았습니다.
